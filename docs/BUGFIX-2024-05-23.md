# 录音和语音识别修复 (2024-05-23)

## 问题描述

用户反馈在运行程序时遇到以下问题：

1. **录音时波形显示异常**：录音开始后应该显示音频波形，但实际只显示粉色静态波形
2. **语音识别结果为空**：AI模型识别结果总是返回空内容或广告信息
3. **VAD过滤过于严格**：faster-whisper的语音活动检测把所有音频都过滤掉了

## 根本原因分析

通过分析日志发现：

1. **设备问题**：系统只检测到 `BlackHole 2ch` 虚拟音频设备，这是一个没有真实麦克风的Mac mini
2. **VAD参数过严**：默认的语音活动检测参数对虚拟音频设备和低音量输入过于严格
3. **音频电平计算不准确**：现有的音频电平计算算法对低音量输入不够敏感

## 修复方案

### 1. 优化VAD参数

修改 `core/engine.py` 中的转写参数：

```python
# 降低无语音检测阈值从0.6到0.3
no_speech_threshold=0.3,

# 优化VAD参数
vad_parameters={
    "min_silence_duration_ms": 200,  # 从500ms降低到200ms
    "speech_pad_ms": 100,            # 添加语音填充
    "threshold": 0.3                  # 从0.5降低到0.3
}
```

### 2. 改进音频电平计算

优化 `core/recorder.py` 中的音频电平算法：

- 使用RMS (Root Mean Square) 算法
- 应用对数缩放提高低音量可见性
- 为虚拟音频设备提供额外增益
- 添加平滑处理避免跳动

### 3. 增强设备检测和初始化

- 添加多种音频配置自动尝试
- 改进设备验证和错误处理
- 详细的日志输出便于调试

### 4. 修复快捷键监听

修复 `core/hotkey_listener.py` 中缺失的导入：
- 添加 `CGEventGetFlags` 和 `kCFRunLoopCommonModes`

## 技术改进

1. **保持模型状态**：避免每次转写重新加载模型，提高性能
2. **更好的错误提示**：提供更友好的用户反馈信息
3. **日志优化**：添加详细的调试信息
